## Context

`AdminService.RemoveNode` on the target retires the node locally
(`admin_service.rs:326`) and cancels the shutdown token; `main.rs:428` reacts
by cancelling the rest and exiting ~500 ms later. `GossipTask::run`
(`gossip.rs:104`) selects on that cancellation before its next tick, so
`persist_directory` never runs between the retire and the exit. The tombstone
the node just wrote for itself is only in memory when the process dies.

The boot guard at `main.rs:276` — which exists so a retired node refuses to
start — then reads a persisted directory with no self-tombstone and lets the
node come up. It is refused only on the *next* restart, after gossip has
re-taught it its own tombstone, so the window is a full zombie boot: the node
rejoins, serves, and is dialled by peers that have already retired it.

tk-c47e's reviewer saw this shape and parked it on tk-ad1d for the
tombstoned-on-its-behalf path, where the node is dead and cannot flush
anything. It also hits graceful self-retirement, where the node is alive and
could — and that is the path the guard was written for. `main.rs:276` has no
test.

## Blast radius

`crates/ggap-server/src/admin_service.rs` (the retire path),
`crates/ggap-node/src/main.rs` (shutdown ordering, and the untested guard at
:276), possibly `crates/ggap-consensus/src/gossip.rs` if the flush moves into
the task's shutdown arm. Related but distinct: tk-ad1d.

### Q1 [open] How does a self-retiring node get its tombstone onto disk before it exits?
- a) Write through in retire() — RemoveNode persists the directory synchronously before answering, so the tombstone is durable no matter how the shutdown races; costs a blocking write on an admin RPC
- b) Flush in GossipTask's shutdown arm — the task persists once more on cancellation, keeping all directory writes in the one place that owns them; still lost if the process dies without running the arm
- c) Both — write through on retire and flush on shutdown, since they cover different failures (a crash mid-retire vs. any other in-memory drift)
