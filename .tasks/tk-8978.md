## Context

The first increment, and it ships alone: the registry gains the ordering rule
that the old self-seed never had, while the membership-derived feed keeps
running. Nothing depends on it yet, which is what makes it safe to land first.

- `NodeAddrs` in the directory becomes a descriptor carrying an incarnation
  (`registry.rs` directory map, `GossipNode` in `types.proto`).
- `merge_directory` orders by incarnation, highest wins, replacing the
  whole-value last-write-wins rule tk-11b6 left in place. Its provenance
  argument does not survive this — rewrite that comment, do not patch it.
- `GossipTask` publishes this node's own descriptor each tick, from config.
  This is the self-seed restored; say so in the code comment without narrating
  tk-11b6.
- The membership-derived merge stays for now. Both feeds write the same map, so
  decide and document which wins while they coexist — a membership entry has no
  incarnation.
- No liveness or last-seen tracking. The directory carries addresses and an
  incarnation, nothing else.
