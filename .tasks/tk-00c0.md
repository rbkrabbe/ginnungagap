## Context

`admin_service.rs:63-73` returns membership-derived `NodeInfo` for a hosted
shard and falls back to `ids_to_node_infos` (:108) for the rest. Once membership
has no addresses the two paths collapse into one: ids from membership or the
gossiped `ShardEntry`, addresses always from the directory.

Watch the `last_observed_age_ms` semantics — hosted shards report 0 today, and
that should stay tied to the consensus data, not to directory freshness.
