## Context

Clicking the veil closes the Add learner modal mid-edit, losing typed node id and addresses. Modals should close only on Cancel, on the confirming action, or on ESC.

Same click-outside-to-dismiss pattern appears in six modals across three screens:
- console/src/screens/Membership.tsx:291 (Add learner), :317 (ChangeMembership)
- console/src/screens/Kv.tsx:559 (Delete), :583 (CAS), :634 (shared/generic modal)
- console/src/screens/Shards.tsx:442

Modal dismissal is a UI-wide convention, so fix it once via a shared hook/component rather than patching the one modal that was reported.

Behaviour:
- Veil click no longer dismisses.
- ESC cancels, but only when the modal is not mid-flight — mirror the existing `!adding` / `!changing` guards that already hide the Cancel button during an in-flight request, so ESC cannot abandon a modal whose RPC is running.
- Cancel and the confirming action keep their current behaviour.

No proto, server or Rust changes.
