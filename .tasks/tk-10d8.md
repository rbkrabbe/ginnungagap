## Context

CLAUDE.md carries a hard constraint added by tk-1a8d that this epic makes
exactly wrong: "Per-node addresses live in Raft membership, never in gossip."
Invert it, do not soften it — the replacement rule is that consensus carries
identity and the directory resolves it, and the reason is multi-raft.

`docs/ggap-consensus.md` and `docs/ggap-types.md` were rewritten by tk-1a8d to
describe the derived directory. Both need the opposite. State the end state; do
not narrate the reversal.

## Acceptance

- [x] No doc describes the directory as derived from membership. The phrase
      "membership-derived" no longer appears anywhere outside
      `ggap-server/src/metrics.rs`, where it is about histograms.
- [x] CLAUDE.md carries the inverted constraint and a Current State that matches.
      The hard constraint now reads "Consensus carries identity; the directory

## Notes

`docs/ggap-storage.md` was left alone deliberately. It calls the *persisted*
directory "a cache of gossip", which is still exactly right: the in-memory
directory is the source of truth, and the on-disk record is a copy of it that
buys immediacy on the next boot.
