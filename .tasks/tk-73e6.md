## Context

cmd_edited (bin/tk:581-586) appends every edited path to touched without excluding .tasks/**. CLAUDE.md requires committing .tasks/*.md in the same commit as the code it describes, so writing acceptance criteria always costs one slot against the source-file budget.

Effect: every task trips scope_check one real file early. An s task (scope_limit_s = 2) gets one source file plus its own task file; an m gets five instead of six.

Hit on tk-85c1: a two-file fix (crates/ggap-consensus/src/node.rs, crates/ggap-server/tests/three_node_cluster.rs) was reported as 3 files over a limit of 2. Neither remedy the hook offers was right — the work was genuinely s, and re-sizing to m would have misrepresented it and triggered an adversarial review the size rules do not call for.

Fix: exclude paths under .tasks/ from the touched list in cmd_edited, so the budget counts only the code the size refers to.

Note bin/tk is tracked, unlike .claude/ which is gitignored — so this is a real repo change, not a local-only one.

Second, smaller thing found at the same time: tk done releases the claim, so a commit that follows it is blocked by the gate with 'no task claimed'. Working order is commit, then tk done, then a task-only commit to record the closure. Worth either documenting in CLAUDE.md or making tk done keep the claim briefly.
